# 기능 추가 방법 (개발 메모)

프로그램은 `presets/` 안의 폴더 하나를 탭 하나로 보여 준다. 새 기능 = 새 폴더.

```
presets/08_새기능/
  workflow_api.json   ComfyUI 워크플로 (API 형식)
  preset.json         화면에 보여 줄 칸과, 그 칸이 워크플로의 어느 노드 입력에 들어갈지
```

## 1. 워크플로를 API 형식으로

ComfyUI에서 워크플로를 완성한 뒤 메뉴 **Workflow → Export (API)** 로 저장한다.
(개발용 변환기: 프로젝트 `app/dev/ui2api.py` + `object_info.json`)

## 2. preset.json

```json
{
  "name": "탭 이름", "group": "그리기", "order": 8, "description": "한 줄 설명",
  "fields": [
    {"id": "prompt", "type": "textarea", "label": "그릴 것", "default": "...",
     "targets": [{"node": "3", "input": "text"}]},
    {"id": "image", "type": "image", "label": "원본 그림", "targets": [{"node": "10", "input": "image"}]},
    {"id": "strength", "type": "number", "label": "바꾸는 정도", "default": 0.5, "min": 0.1, "max": 1, "step": 0.05,
     "advanced": true, "targets": [{"node": "9", "input": "denoise"}]},
    {"id": "seed", "type": "seed", "label": "시드", "targets": [{"node": "9", "input": "seed"}]}
  ],
  "outputs": [{"node": "12", "label": "결과"}, {"node": "14", "label": "투명", "send": false}],
  "postprocess": []
}
```

칸 종류 (`type`):

| type | 화면 | 값 |
|---|---|---|
| `text`, `textarea` | 글자칸 | 글자. `template` 으로 다른 칸과 합칠 수 있음: `"template": "{subject}, {style}"`. `presets: [{label, value}]` 이면 칸 위에 값을 채우는 버튼 |
| `number` | 슬라이더 + 숫자 | `min`, `max`, `step` (step에 소수점이 있으면 소수) |
| `choice` | 고르기 | `options[].set` 에 적은 노드 입력값들을 한꺼번에 바꿈. `options[].remove: [노드...]` 는 그 노드를 지움. `ratio` + `auto_from` 이면 그림 비율로 자동 선택 |
| `seed` | 숫자 + "매번 새로" | 여러 노드에 같은 시드를 넣을 수 있음 |
| `image` | 그림 올리기 | ComfyUI input/picapp 에 올린 뒤 파일 이름을 넣음 (LoadImage) |
| `images` | 그림 여러 장 (순서 바꾸기, 빼기) | 프리셋에 `"repeat_over": "이 칸 id"` 를 적으면 그림마다 워크플로를 한 번씩, 같은 시드로 돌린다 (애니메이션 프레임). 후처리는 모든 프레임을 순서대로 한꺼번에 받는다 |
| `mask_image` | 그림 올리기 + 붓으로 칠하기 | 칠한 곳이 알파 0 인 PNG (LoadImage 의 MASK 출력으로 나옴) |
| `palette` | 팔레트 고르기 + 색 견본 | `{colors, guide, snap}`. `targets` 에 `"append": true` 면 색 이름을 그 글자 입력 끝에 붙임 (글자칸들보다 뒤에 둘 것) |
| `toggle` | 체크 칸 | 끄면 `bypass_off`, 켜면 `bypass_on` 의 노드들을 건너뛴다 (`{"node", "input"}`: 그 노드를 쓰던 곳이 이 입력을 바로 씀). `requires` 에 노드 이름을 적으면 켤 때 설치 여부를 확인 |

워크플로는 보낼 때 저장/미리보기 노드에서 닿지 않는 노드를 지운다. 그래서 꺼 둔 기능의 확장 노드는 설치돼 있지 않아도 된다.

공통: `label`, `hint`(칸 아래 설명), `advanced`(고급 설정 안에 넣기), `default`.
글자칸(`text`, `textarea`)은 한글이 들어오면 영어로 번역해서 넣는다 (`server.py` 의 `translate_prompt`, 모델 opus-mt-ko-en, CPU).
번역하면 안 되는 칸은 `"translate": false`.
`outputs[].hidden: true` 면 결과 칸에 안 보이고 후처리 재료로만 쓴다. 후처리 단계의 `"fields": [칸 id...]` 는 그 칸 값들을 params 로 넘긴다. 후처리가 `(그림, 이름, 꼬리표)` 세 개를 돌려주면 한 그림에서 여러 장을 낼 수 있다.
`outputs[].send: false` 면 결과 카드에 "고치기로 보내기" 버튼이 없다 (투명 그림 등).

뼈대 그림 칸: `toggle` 에 `"skeleton_for": "그림 칸 id"` 를 적으면, 그 칸에 OpenPose 뼈대 그림(검은 바탕 + 진한 색 막대)이 들어올 때 저절로 켜지고 아니면 꺼진다.

그림 칸 `"required": false` + `"bypass_empty": [{"node", "input"}]`: 그림을 안 올리면 그 노드를 건너뛴다 (예: 캐릭터 참고 IP-Adapter 노드 53). `requires` + `"setup": "설치 안내 제목"` 은 확장이 없을 때 알려 줄 안내 이름.

`loras` 칸: 값은 `[{name, strength, word}]`. `server.py` 의 `apply_loras` 가 CheckpointLoaderSimple 의 MODEL·CLIP 을 쓰던 모든 노드를 마지막 LoraLoader 로 돌린다.

도구 탭: `preset.json` 에 `"tool": "pose3d"` 처럼 적으면 워크플로 없이 `web/pose3d.js` 의 `mount(root, ui)` 화면을 연다 (처음 열 때 불러옴). 예: `presets/03p_pose3d` (3D 자세 만들기, three.js 는 `web/vendor`).

## 3. ComfyUI 밖의 처리

도트 변환, 스프라이트 시트처럼 노드로 어려운 일은 `postprocess/` 에 파이썬 파일로 두고
`preset.json` 의 `postprocess` 에 적는다. 자세한 형식은 `postprocess/README.md`.
화면 칸 값으로 켜고 끄려면 `"params_from": "칸 id"`, `"enabled_key": "snap"` (예: 팔레트 맞추기).

| LoRA 선택 | 완료: `loras` 칸 (서버가 체크포인트 뒤에 LoraLoader 를 줄줄이 끼움, `prompt_targets` 에 파일 이름 단어를 붙임) |
| Aseprite 연결 | 완료: `aseprite/` (빌드 스크립트 `build_aseprite.ps1`, 시트→애니메이션 `sheet_to_anim.lua`), `server.py` 의 `aseprite_open`/`aseprite_import`. 후처리가 네 번째 값에 `{"sheet": {cell, count, cols, ms}}` 를 주면 Aseprite 에서 프레임으로 나눠 연다 |
| Claude 연결 (MCP) | 완료: `claude_mcp.py` (MCP 표준 입출력, Claude 앱 등록 `--install`) + `claude_tools.py` (도구들, 바뀌면 저절로 다시 읽음). 프리셋을 그때그때 읽으므로 새 기능 폴더를 더해도 고칠 것 없음. 새 칸 종류(`type`)를 만들면 `claude_tools.py` 의 `prepare_values`·`TYPE_HELP` 에도 더한다 |
