# Aseprite 빌드하고 그림 도구에 붙이기

Aseprite 는 도트 그림 프로그램이에요. 원래 유료 프로그램이지만 소스 코드가 공개돼 있어서,
**내 PC 에서 직접 빌드(만들기)하면 개인용으로 무료로 쓸 수 있어요.**

> 약속 하나: 내가 빌드한 Aseprite 는 **나만** 써야 해요. exe 를 친구에게 주거나 인터넷에 올리면 Aseprite 사용 약관(EULA) 위반이에요.
> 그래서 그림 도구에는 exe 가 들어 있지 않고, 빌드하는 스크립트만 들어 있어요.

## 1. 빌드하기 (한 번만, 1~2시간)

1. 노트북 충전기를 꽂아요. C 드라이브에 빈 공간이 **15GB** 이상 있어야 해요.
2. `C:\AI-PIC\PicApp\aseprite\Aseprite_빌드.bat` 을 더블클릭해요.
3. 파란 글씨로 [1/7] ~ [7/7] 단계가 나와요. 그냥 기다리면 돼요.
   - **[2/7]** 에서 처음이면 "Visual Studio Build Tools"(C++ 컴파일러, 마이크로소프트 무료 도구)를 설치해요.
     **"이 앱이 디바이스를 변경하도록 허용하시겠어요?"** 창이 뜨면 **[예]** 를 눌러요. 설치 창이 저절로 진행돼요 (20~40분).
   - **[7/7]** 빌드는 20~60분 걸려요. 글자가 계속 올라가면 잘 되고 있는 거예요.
4. 초록 글씨로 **다 됐어요!** 가 나오면 끝이에요.
   - 실행 파일: `C:\AI-PIC\Aseprite\build\bin\aseprite.exe`
   - 바탕화면에 **Aseprite (내가 빌드)** 바로가기도 생겨요.

중간에 멈췄을 때: 빨간 글씨를 읽어 보고, 인터넷 문제면 **bat 을 다시 실행**하면 돼요. 이미 한 단계는 건너뛰고 이어서 해요.
그래도 안 되면 `C:\AI-PIC\Aseprite\build_log.txt` 를 보내 주세요.

### 새 버전으로 바꾸기

Aseprite 새 버전이 나오면 `Aseprite_빌드.bat` 을 다시 실행해요. 새 정식판이 있으면 받아서 다시 빌드하고, 없으면 몇 분 만에 끝나요.
(베타판은 받지 않고 정식판만 받아요.)

### 만들어지는 폴더

```
C:\AI-PIC\Aseprite\
  src\     Aseprite 소스
  deps\    Skia (Aseprite 가 화면을 그리는 데 쓰는 라이브러리, 미리 만들어진 것을 받음)
  tools\   CMake, Ninja (빌드 도구, 설치하지 않고 이 폴더에만 둠)
  build\   빌드 결과 (bin\aseprite.exe)
```

다 지우고 싶으면 이 폴더를 통째로 지우면 돼요. Visual Studio Build Tools 는 Windows 설정 → 앱에서 지워요.

## 2. 그림 도구에서 쓰기

빌드가 끝난 뒤 그림 도구(`그림도구_실행.bat`)를 켜면, 결과 카드마다 **Aseprite로 열기** 버튼이 생겨요.
(그림 도구가 이미 켜져 있었으면 몇 초 뒤 저절로 생겨요.)

- **그림 한 장** (도트 만들기 결과 등): Aseprite 에 그대로 열려요. 점을 고치고 **Ctrl+S** 로 저장해요.
- **스프라이트 시트** (스프라이트 애니메이션 결과의 "시트"): 프레임으로 나뉜 **애니메이션**으로 열려요.
  프레임 시간도 그림 도구에서 정한 대로 들어가 있어요. 아래 타임라인에서 프레임을 고치고, 재생(Enter)해 보고, **Ctrl+S** 로 저장해요.
  (같은 이름의 `.aseprite` 파일로 저장돼요. 다시 **Aseprite로 열기** 를 누르면 고치던 그 파일이 열려요.)
- 저장한 뒤 그림 도구로 돌아와 **고친 것 가져오기** 를 누르면 카드 그림이 고친 것으로 바뀌어요.
  시트는 Aseprite 에서 다시 시트로 뽑아 와요. 그 뒤 **다른 기능으로 보내기** 도 고친 그림으로 보내요.

파일 위치: 고치는 그림은 `C:\AI-PIC\PicApp\results\` 에 있어요.
(ComfyUI 결과를 열면 그 폴더로 복사해서 열어요. ComfyUI output 의 원본은 그대로 남아요.)

스팀이나 공식 사이트에서 산 Aseprite 가 이미 있으면 빌드하지 않아도 저절로 찾아요.
다른 곳에 있으면 `PicApp\settings.json` 에 `"aseprite_exe": "D:\\어딘가\\Aseprite.exe"` 를 넣어요.

## 안 될 때

| 보이는 것 | 할 일 |
|---|---|
| 창이 바로 닫혀요 | `Aseprite_빌드.bat` 을 `C:\AI-PIC\PicApp\aseprite\` 안에서 실행했는지 확인 |
| "빈 공간이 … 필요해요" | 필요 없는 파일을 지우고 다시 |
| "C++ 빌드 도구 설치가 끝나지 않았어요" | [예] 를 눌렀는지 확인하고 다시. 그래도 안 되면 PC 를 다시 시작하고 다시 |
| "GitHub 에 연결하지 못했어요" / 받는 중 오류 | 인터넷 확인 후 다시 실행 |
| 빌드 중 오류, 다시 해도 같은 곳에서 멈춤 | `Aseprite_처음부터_빌드.bat` 을 실행 (빌드 폴더만 지우고 다시 해요) |
| 그림 도구에 **Aseprite로 열기** 가 안 보여요 | `C:\AI-PIC\Aseprite\build\bin\aseprite.exe` 가 있는지 확인, 그림 도구 검은 창을 닫고 다시 켜기 |
| "먼저 'Aseprite로 열기' 를 눌러 주세요" | 시트는 열기를 한 번 한 뒤에 가져올 수 있어요 |
