# 그림 도구 설치와 사용

ComfyUI를 뒤에서 그대로 쓰고, 버튼과 입력칸만 있는 화면을 브라우저에 띄우는 프로그램이에요.
따로 설치할 것은 없어요. ComfyUI 포터블에 들어 있는 파이썬으로 돌아가요.

## 설치 (한 번만)

1. `PicApp.zip` 을 받아서 압축을 풀어요.
2. 나온 `PicApp` 폴더를 `C:\AI-PIC\` 안에 넣어요. 이렇게 되면 돼요.
   ```
   C:\AI-PIC\ComfyUI_windows_portable\
   C:\AI-PIC\PicApp\          ← 여기
   ```
3. 끝이에요.

## 켜기

`C:\AI-PIC\PicApp\그림도구_실행.bat` 을 더블클릭해요.

- ComfyUI가 꺼져 있으면 저절로 켜요 (검은 창이 하나 더 뜨고, ComfyUI 화면도 브라우저에 열릴 수 있어요. 그 탭은 닫아도 돼요).
- 잠시 뒤 브라우저에 **그림 도구** 화면이 열려요. 주소는 `http://127.0.0.1:8190`.
- 오른쪽 위가 **ComfyUI 연결됨** 이 되면 쓸 수 있어요. 처음 켤 때는 1분쯤 걸릴 수 있어요.
- 끌 때는 검은 창 두 개(그림 도구, ComfyUI)를 닫아요.

바탕화면에 바로가기를 만들려면 `그림도구_실행.bat` 을 오른쪽 클릭 → **바로 가기 만들기** → 바탕화면으로 옮겨요.

## 쓰는 법

왼쪽에서 기능을 고르고, 칸을 채우고, **그리기** 를 눌러요. 결과는 오른쪽에 나오고 ComfyUI의 `output` 폴더에도 저장돼요.
오른쪽 위 **결과 폴더 열기** 를 누르면 그 폴더가 탐색기로 열려요. 팔레트 맞춤 그림도 같은 폴더에 저장돼요.

| 기능 | 하는 일 |
|---|---|
| 캐릭터 그리기 | 설명 → 캐릭터 + 배경 제거 (원본, 투명, 게임 에셋 크기) |
| 컨셉아트 | 가로 배경·장면 (초안 768 → 완성 1152) |
| 자세 참고 캐릭터 | 참고 그림의 자세를 따라 그리기. 참고 그림을 올리면 비율이 저절로 맞춰져요 |
| 3D 자세 만들기 | 3D 뼈대의 관절을 끌어서 자세를 잡고, 뼈대 그림으로 자세 참고 캐릭터나 애니메이션에 보내기 |
| 얼굴 / 손 / 소품 / 어울림 보정 | 그림을 올리고 고칠 곳을 붓으로 칠한 뒤 그리기 |
| 분위기 바꾸기 | 그린 그림의 시간·날씨·진영 느낌을 바꾸기. 선을 붙잡아 모양과 자세는 남겨요 |
| 도트 만들기 | 그림을 게임용 도트(픽셀아트)로. 줄이기, 색 줄이기(팔레트), 투명 배경, 외곽선 |
| 고품질 다듬기 (SDXL) | 마음에 든 그림을 SDXL로 1024 크기에서 한 번 더 다듬기. 모델을 따로 받아야 해요 |
| 스프라이트 애니메이션 | 자세 그림 여러 장 → 같은 캐릭터를 자세마다 그려 스프라이트 시트 + 움직임 미리보기(GIF). 이미 그린 그림을 묶기만 해도 돼요 |

- **다른 기능으로 보내기**: 결과 그림 아래 버튼을 누르면 고치기나 분위기 바꾸기로 바로 넘어가요. 그림을 따로 저장했다가 올릴 필요가 없어요.
- **시드**: 같은 캐릭터를 다시 얻으려면 **매번 새로** 를 끄세요. 방금 쓴 시드가 칸에 남아 있어요.
- **고급 설정**: 그림체 단어, 피할 것, 세기 같은 칸이 들어 있어요. **글자·숫자를 처음 값으로** 로 되돌릴 수 있어요.
- 쓴 글자와 숫자는 브라우저에 기억돼서 다음에 켜도 남아 있어요.
- 고칠 그림에 투명 PNG를 올리면 투명한 곳을 흰색으로 채워요. 그래도 배경 있는 원본을 쓰는 게 좋아요.
- 프롬프트는 명령문이 아니라 **결과 모습** 으로 써요. 없앨 것은 **없앨 것/피할 것** 칸에.

## 3D 자세 만들기

1. 관절(색 공)을 마우스로 끌어요. 손목·발목을 끌면 팔꿈치·무릎이 저절로 따라 굽고, 팔꿈치·무릎·고개·목은 그 관절에서 돌아가요. 빈 곳을 끌면 보는 방향이 돌아가고, 휠로 가까이·멀리 볼 수 있어요.
2. **기본 자세**(서기, 걷기 1~4, 달리기, 점프, 앉기, 검 들어 올리기, 주문 외우기, 손 흔들기)에서 시작하면 편해요. **좌우 뒤집기**, **되돌리기**, **자세 저장**(PicApp\poses 폴더에 남아요)도 있어요.
3. 뼈대 그림은 **지금 보는 방향 그대로** 만들어져요. 정면·옆·뒤 버튼으로 맞추세요. 아래 작은 검은 그림이 실제로 보낼 뼈대 그림이에요.
4. **자세 참고 캐릭터로 보내기**: 그 탭으로 넘어가고 '이미 뼈대 그림이에요'가 저절로 켜져요. 그 다음 그리기만 누르면 돼요.
5. **애니메이션 프레임으로 더하기**: 탭을 넘기지 않고 프레임을 하나씩 모아요. 예: 걷기 1 → 더하기, 걷기 2 → 더하기, 걷기 3, 걷기 4. 다 모으면 스프라이트 애니메이션 탭에서 만들기.

애니메이션 프레임을 모을 때는 보는 방향과 크기를 바꾸지 마세요. 그래야 프레임끼리 캐릭터 크기와 위치가 맞아요.
3D 화면은 three.js(MIT 라이선스, `web\vendor`)를 프로그램 안에 넣어 두어서 인터넷 없이 돼요.

## 캐릭터 닮게 그리기 (캐릭터 참고 그림)

**자세 참고 캐릭터**와 **스프라이트 애니메이션**에 '캐릭터 참고 그림' 칸이 있어요. 이미 그린 캐릭터 그림을 넣으면 얼굴·옷·색을 보고 새 자세로 그려요 (IP-Adapter 방식).

1. 마음에 든 캐릭터의 결과 카드에서 **다른 기능으로 보내기 → 자세 참고 캐릭터 · 캐릭터 참고 그림**.
2. 자세는 자세 참고 그림이나 3D 자세 만들기에서 넣어요.
3. **그릴 것** 칸에는 처음 그릴 때 쓴 설명을 그대로 넣으면 더 비슷해져요.
4. **캐릭터 닮게 하는 세기**: 덜 닮으면 올리고, 참고 그림의 자세나 배경까지 따라오면 내려요 (0.6~0.8).
5. 안 쓰려면 칸 아래 **빼기**. 비워 두면 예전처럼 설명만 보고 그려요.

LoRA만큼 똑같지는 않지만 설명만 쓸 때보다 훨씬 비슷해요. 애니메이션 프레임끼리도 덜 달라져요.

### 캐릭터 닮게 그리기 준비 (한 번만)

1. ComfyUI Manager → **Custom Nodes Manager** 에서 `ComfyUI_IPAdapter_plus` (만든 사람 cubiq) 를 설치해요.
2. 모델 파일 두 개를 받아 넣어요 (둘 다 Apache-2.0 / MIT, 게임에 써도 돼요).
   - `ComfyUI\models\ipadapter\` (폴더가 없으면 만들기) 에
     https://huggingface.co/h94/IP-Adapter/resolve/main/models/ip-adapter-plus_sd15.safetensors (약 100MB)
   - `ComfyUI\models\clip_vision\` 에
     https://huggingface.co/h94/IP-Adapter/resolve/main/models/image_encoder/model.safetensors (약 2.5GB)
     받은 뒤 이름을 **`CLIP-ViT-H-14-laion2B-s32B-b79K.safetensors`** 로 바꿔요. 이름이 다르면 못 찾아요.
3. ComfyUI 검은 창을 닫고 그림 도구를 다시 켜요.

4GB 그래픽 메모리에서도 돌아가요. 한 장에 몇 초 더 걸려요.

## LoRA (캐릭터·그림체 고정)

그리기·고치기·분위기·애니메이션 탭에 **LoRA** 칸이 있어요 (SDXL 탭은 빼고).

1. LoRA 파일(`.safetensors`)을 `ComfyUI\models\loras\` 에 넣어요.
2. 그림 도구에서 **목록 새로 읽기** → LoRA 고르기. **+ LoRA 더하기** 로 캐릭터 LoRA 와 그림체 LoRA 를 같이 써도 돼요 (4개까지).
3. **세기**: 0.8 에서 시작. 그림이 망가지거나 너무 똑같으면 내리고, 덜 닮으면 올려요.
4. **이름 단어**: 켜 두면 파일 이름(예: steamgirl)을 프롬프트 끝에 붙여요. 학습 노트로 만든 LoRA 는 이 단어로 부르게 학습돼서 켜 두세요. 남이 만든 LoRA 는 설명에 적힌 단어를 직접 쓰고 이 칸은 꺼도 돼요.

LoRA 만들기는 `LoRA_학습_Colab.ipynb` (Colab 무료 GPU) 로 해요.
1. https://colab.research.google.com 에서 **파일 → 노트 업로드** 로 이 파일을 열어요.
2. 노트 맨 위 안내대로 구글 드라이브 `내 드라이브/LoRA학습/이름/` 에 그림을 넣고, 이름·종류를 고른 뒤 **런타임 → 모두 실행**.
3. 다 되면 `이름.safetensors` 를 받아 위 1번처럼 넣어요.

## 품질 (2단계 그리기, 얼굴·손 자동 다듬기)

**캐릭터 그리기**와 **자세 참고 캐릭터**에 **품질** 칸이 있어요. 처음에는 모두 켜져 있어요.

- **2단계로 그리기**: 작게 그린 뒤 1.5배로 키우면서 한 번 더 다듬어요. 선과 장식이 또렷해지고, 원본 그림이 768(세로 전신은 768x1152)로 커져요.
- **얼굴 자동 다듬기 / 손 자동 다듬기**: 다 그린 그림에서 얼굴과 손을 찾아 확대해서 다시 그려요. 못 찾으면 그대로 둬요.
- 켤수록 시간이 더 걸려요. 빨리 여러 장 뽑아 볼 때는 끄고, 마음에 드는 시드를 찾은 뒤 켜서 다시 그리면 좋아요.

### 얼굴·손 자동 다듬기 준비 (한 번만)

확장 노드 두 개와 모델 두 개가 필요해요. 없으면 그림 도구가 "필요한 확장 노드가 없어요"라고 알려 줘요. 그때는 두 칸을 끄면 나머지는 그대로 쓸 수 있어요.

1. ComfyUI 화면(`http://127.0.0.1:8188`)에서 **Manager** → **Custom Nodes Manager**.
2. `Impact Pack` 을 검색해서 **ComfyUI Impact Pack** 을 Install, `Impact Subpack` 을 검색해서 **ComfyUI Impact Subpack** 을 Install.
3. **Manager** → **Model Manager** 에서 `face_yolov8m` 과 `hand_yolov8s` 를 검색해 각각 Install.
   목록에 없으면 https://huggingface.co/Bingsu/adetailer 에서 `face_yolov8m.pt`, `hand_yolov8s.pt` 를 받아
   `ComfyUI\models\ultralytics\bbox\` 폴더에 넣어요.
4. ComfyUI 검은 창을 닫고 다시 켜요.

## 분위기 바꾸기

1. 그림을 올리거나, 결과 카드에서 **다른 기능으로 보내기 → 분위기 바꾸기** 를 눌러요.
2. **그림 설명** 에 그림에 무엇이 있는지 짧게 써요 (예: 기사 소녀, 전신).
3. **바꿀 분위기** 버튼(밤, 노을, 비 오는 날, 눈, 어두운 판타지, 밝고 화사하게, 스팀펑크로, 중세 마법사로)을 누르거나 직접 써요.
4. **얼마나 바꿀지** 로 조절해요. 0.3 쯤은 색과 빛만, 0.55 는 옷 색과 배경까지, 0.8 이상은 많이 바뀌어요.
5. **모양 지키기** 가 켜져 있으면 선을 붙잡아 두어서, 많이 바꿔도 캐릭터 모양과 자세가 남아요. 결과의 **선 확인** 에서 붙잡은 선을 볼 수 있어요.

### 모양 지키기 준비 (한 번만)

선을 붙잡는 ControlNet 모델 `control_v11p_sd15_lineart_fp16.safetensors` 가 필요해요. 자세 참고에 쓰는 openpose 모델과 같은 곳에 있어요.

- ComfyUI **Manager → Model Manager** 에서 `lineart` 를 검색해 **ControlNet v1.1 lineart (fp16)** 을 Install, 또는
- https://huggingface.co/comfyanonymous/ControlNet-v1-1_fp16_safetensors 에서 받아 `ComfyUI\models\controlnet\` 에 넣어요.

선을 뽑는 작은 모델은 처음 쓸 때 저절로 받아요 (인터넷 필요). 모델이 없을 때는 **모양 지키기** 를 끄면 나머지는 그대로 돼요.

## 도트 만들기

1. 그림을 올리거나 결과 카드에서 **다른 기능으로 보내기 → 도트 만들기**. 투명 그림(투명, 게임 에셋)을 보내면 배경을 그대로 써요.
2. **도트 크기**: 가장 긴 쪽 픽셀 수. 캐릭터는 32~64가 무난해요.
3. **정사각 칸에 맞추기**: 켜면 모든 결과가 32x32 처럼 같은 칸 크기가 되고 캐릭터가 아래 가운데에 놓여요. 스프라이트 시트로 묶을 때 좋아요.
4. **색 팔레트**를 고르면 그 색만 써요. 안 고르면 **색 수** 만큼 그림에서 골라요. 진영 팔레트를 쓰면 에셋끼리 색이 맞아요.
5. **1픽셀 외곽선**: 둘레에 어두운 선을 둘러요.

결과는 **실제 크기**(게임에 넣을 파일)와 **확대 미리보기** 두 장이에요. 이 기능은 그림을 새로 그리지 않아서 몇 초면 끝나요.

## 고품질 다듬기 (SDXL)

평소 그림은 가벼운 SD 1.5로 빨리 뽑고, 마음에 든 것만 큰 모델(SDXL)로 다듬는 방식이에요.

1. 결과 카드에서 **다른 기능으로 보내기 → 고품질 다듬기** (그림을 직접 올려도 돼요).
2. **그림 설명**에 처음 그릴 때 쓴 설명을 넣어요.
3. **얼마나 다듬을지**: 0.25는 거의 그대로 또렷하게만, 0.35(기본)는 질감과 세부를 다시, 0.5 넘으면 얼굴과 옷 모양도 바뀌어요.
4. **다듬기**. 그래픽 메모리가 4GB라서 ComfyUI가 모델을 나눠 올리느라 느려요. 한 장에 1분 넘게 걸릴 수 있어요. 처음 한 번은 모델을 읽느라 더 걸려요.

### SDXL 모델 준비 (한 번만)

1. 아래 파일을 받아 `ComfyUI\models\checkpoints\` 에 넣어요 (약 7GB, 디스크 여유를 확인하세요).
   - DreamShaper XL Turbo v2.1 (기본, 빠름): https://huggingface.co/Lykon/dreamshaper-xl-v2-turbo/resolve/main/DreamShaperXL_Turbo_v2_1.safetensors
   - 라이선스는 OpenRAIL++ 이에요. 게임과 개인 작품에 써도 되고, 금지된 용도(남을 해치는 그림 등)만 피하면 돼요.
2. ComfyUI 검은 창을 닫고 그림 도구를 다시 켜요.
3. (선택) 고급 설정의 **SDXL 모델**에서 'SDXL 기본 1.0'을 고르려면 `sd_xl_base_1.0.safetensors` (https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0) 도 같은 폴더에 넣어요. 보통은 Turbo 하나면 충분해요.

메모리가 부족하다고 나오면 **크기**를 '800급'으로 바꾸고, 브라우저 탭이나 게임을 닫고 다시 해 보세요.

## 스프라이트 애니메이션

1. **만드는 방법**
   - **자세 그림대로 새로 그리기**: 동작 순서대로 자세 참고 그림(사진도 돼요)을 올리면, 같은 설명·같은 시드로 한 장씩 그려요. 걷기는 4~8장이 무난해요.
   - **이미 그린 그림 묶기**: 다른 기능으로 만든 그림을 순서대로 올리면 시트로 묶기만 해요. 배경이 있으면 '배경 지우기'를 고르세요.
2. 그림은 여러 장을 한꺼번에 끌어다 놓을 수 있어요. 파일 이름 순서(01, 02, …)로 들어가고, 그림 아래 ◀ ▶ 로 순서를 바꾸고 × 로 빼요. 결과 카드의 **다른 기능으로 보내기 → 스프라이트 애니메이션** 은 끝에 한 장을 더해요.
3. **도트로 바꾸기**를 켜면 모든 프레임을 같은 크기·같은 색으로 도트로 바꿔요. 끄면 고급 설정의 **칸 크기**(128/256)로 줄여요.
4. 결과: **시트**(게임에 넣을 파일, 칸 크기가 이름에 적혀 있어요), 도트면 **확대 미리보기**, **움직임 미리보기 GIF**, 그리고 프레임 한 장씩.
5. Unity: 시트를 넣고 Sprite Mode 를 Multiple, Sprite Editor → Slice → Grid By Cell Size 에 칸 크기(예: 64x64)를 넣으면 프레임으로 잘라져요.

알아 둘 것:
- 프레임마다 따로 그리기 때문에 옷 무늬나 얼굴이 조금씩 달라질 수 있어요. 설명에 옷·색을 자세히 쓰고, 품질 칸은 꺼 둔 채(기본) 쓰면 덜 달라져요. 캐릭터 LoRA를 학습하면 훨씬 일정해져요.
- 시간은 프레임 수 x 한 장 시간이에요 (품질을 끄면 한 장에 약 15초). **중지**를 누르면 남은 프레임도 취소돼요.
- 자세 편집 도구에서 만든 막대 그림(OpenPose)을 올릴 때는 **이미 뼈대 그림이에요** 를 켜세요. 같은 뼈대를 조금씩 움직이면 가장 매끄러워요.

## Aseprite 로 고치기

도트 그림·스프라이트 시트를 Aseprite(도트 그림 프로그램)에서 점 단위로 고칠 수 있어요.
처음 한 번 `aseprite\Aseprite_빌드.bat` 으로 Aseprite 를 내 PC 에서 빌드해야 해요 (1~2시간, 자세한 건 `aseprite\Aseprite_빌드_안내.md`).

1. 결과 카드의 **Aseprite로 열기**. 스프라이트 시트는 프레임이 나뉜 애니메이션으로 열려요.
2. Aseprite 에서 고치고 **Ctrl+S** 로 저장.
3. 그림 도구에서 **고친 것 가져오기** 를 누르면 카드가 고친 그림으로 바뀌어요.

## 색 팔레트

**캐릭터 그리기, 컨셉아트, 자세 참고 캐릭터**에 **색 팔레트** 칸이 있어요.

- 팔레트를 고르면 색 견본이 나와요. 견본을 눌러 색을 바꾸고, **+ 색** 으로 더하고, 견본 위의 ×로 빼요.
- **그릴 때 이 색 쪽으로**: 팔레트 색을 `brass and copper color scheme` 같은 말로 프롬프트 끝에 붙여요. 분위기는 따라가지만 다른 색도 조금 섞여요.
- **그린 뒤 이 색만 쓰게 맞추기**: 다 그린 그림의 모든 색을 팔레트 색 중 가장 가까운 색으로 바꾼 **팔레트 맞춤** 그림이 결과에 추가로 나와요. 원본도 그대로 남아요.
- **그림에서 색 뽑기**: 마음에 드는 그림을 올리면 많이 쓰인 색을 뽑아 팔레트로 만들어요.
- **팔레트로 저장**: 이름을 붙여 저장하면 다음부터 목록에서 골라요. `PicApp\palettes` 폴더에 저장돼요.
- 선 색(검정 계열)과 흰색, 피부색을 꼭 넣으세요. 빠지면 가까운 다른 색으로 바뀌어요.
- 들어 있는 **스팀펑크 해방자**, **중세 마법사** 팔레트는 예시예요. 진영 색이 정해지면 고쳐서 같은 이름으로 저장하세요.

## 한글로 쓰기

글자칸에 한글을 쓰면 바로 아래에 **ComfyUI에 들어갈 영어** 칸이 생기고, 번역이 저절로 채워져요. 그림을 그릴 때는 이 영어가 들어가요.

- 번역이 이상하면 영어 칸을 직접 고쳐도 돼요. 한글을 다시 고치면 새로 번역해요.
- 한글과 영어를 섞어 써도 돼요. 한글 부분만 바꾸고, `(갈색 모자:1.2)` 같은 괄호와 강조 숫자는 그대로 둬요.
- **처음 한 번은 인터넷이 필요해요.** 번역 모델(약 300MB)을 `PicApp\models\translate` 에 받고, 그다음부터는 인터넷 없이 돼요. 처음 번역은 1분쯤 걸릴 수 있어요.
- 번역은 CPU로 해서 그림 그리는 그래픽 메모리를 쓰지 않아요.
- 자주 틀리게 번역되는 말은 `PicApp\번역사전.txt` 에 `한글 = english` 형식으로 더하세요. 사전이 번역 모델보다 먼저 적용돼요.

## 업데이트 (새 버전 받기)

그림 도구 화면 오른쪽 위의 **업데이트 확인** 버튼을 써요. 새 버전이 있으면 버튼이 **새 버전 받기** 로 바뀌고 색이 들어와요.

1. **새 버전 받기** 를 누르면 무엇이 바뀌었는지 보여 줘요. **확인** 을 누르면 받아요.
2. 다 받으면 그림 도구가 저절로 다시 켜지고 화면도 새로 고쳐져요. 검은 창을 닫을 필요 없어요.
3. 그대로 남는 것: `settings.json`, `번역사전.txt`(새 판에 생긴 단어만 끝에 덧붙음), `palettes`, `poses`, `results`, `models`.
4. 바뀌거나 빠진 예전 파일은 `PicApp\backup\<날짜-시각>\` 에 남아요. 문제가 생기면 거기서 꺼내 되돌릴 수 있어요.

그림 도구가 아예 안 켜질 때는 `업데이트.bat` 을 더블클릭해도 똑같이 받아요.

- 인터넷이 필요해요 (GitHub 에서 받아요).
- 새 기능이 새 모델이나 ComfyUI 확장을 쓰면, 그 기능 설명의 "준비 (한 번만)" 는 따로 해야 해요.
- 업데이트 받을 곳은 `settings.json` 의 `update_repo` 에 적혀 있어요. 비공개 저장소면 `update_token` 에 읽기 전용 토큰을 넣어요.

## 다른 기기에서 쓰기

그림은 집 컴퓨터의 그래픽카드(RTX 3050)가 그려요. 그래서 방법이 두 가지예요.

### 방법 1 (추천): 집 컴퓨터에 접속해서 쓰기

다른 노트북이나 휴대폰의 브라우저로 집 컴퓨터의 그림 도구를 열어요. 그리는 것은 집 컴퓨터가 하고, 다른 기기에서는 화면만 봐요.
**Tailscale**(무료, 개인용)을 써서 내 기기끼리만 통하는 길을 만들어요. 인터넷 전체에 그림 도구를 여는 것이 아니라서 안전해요.

준비 (한 번만):
1. 집 컴퓨터에 https://tailscale.com/download 에서 Tailscale 을 설치하고 Google 계정 등으로 로그인해요.
2. 쓸 기기(다른 노트북, 휴대폰)에도 Tailscale 을 설치하고 **같은 계정**으로 로그인해요. 휴대폰은 앱스토어/플레이스토어에서 받아요.
3. 집 컴퓨터에서 `PicApp\원격접속_설정.bat` 을 더블클릭 → **1** 을 고르고 → 비밀번호를 정해요 (6글자 이상).
   Windows 관리자 확인 창이 뜨면 **예** 를 눌러요 (방화벽에서 Tailscale 쪽만 열어요).
4. 그림 도구 검은 창이 켜져 있으면 닫고 `그림도구_실행.bat` 을 다시 켜요. 검은 창에 다른 기기용 주소가 나와요. 예: `http://내컴퓨터이름.tail1234.ts.net:8190`

쓰기:
1. 집 컴퓨터는 켜 두고 `그림도구_실행.bat` 도 켜 둬요.
2. 다른 기기에서 Tailscale 을 켜고, 브라우저에 위 주소를 넣어요. 비밀번호를 한 번 넣으면 30일 동안 기억해요.
3. 그림은 결과 카드의 **저장** 버튼으로 지금 쓰는 기기에 받아요. 결과는 집 컴퓨터에도 그대로 저장돼요.

알아 둘 것:
- 집 컴퓨터가 **잠자기**에 들어가면 접속이 끊겨요. 노트북이면 **설정 → 시스템 → 전원** 에서 "전원 연결 시 절전 안 함", 덮개를 닫을 때 "아무것도 안 함" 으로 바꿔요.
- **결과 폴더 열기**, **Aseprite로 열기** 는 집 컴퓨터 화면에서 열리는 기능이라 다른 기기에서는 안 보여요.
- 끄려면 `원격접속_설정.bat` → **3**.
- 같은 와이파이의 기기는 Tailscale 없이 들어오게 하려면 **2** 를 골라요. 이때 주소는 검은 창에 "같은 와이파이에서는" 으로 나와요.
- 공유기 포트 열기(포트 포워딩)로 인터넷에 그대로 여는 것은 하지 마세요. 누구나 집 컴퓨터를 두드릴 수 있게 돼요.
- 그림 도구가 아니라 집 컴퓨터 화면 전체(Aseprite 포함)를 쓰고 싶으면 **Chrome 원격 데스크톱**(무료, https://remotedesktop.google.com)도 돼요. 대신 화면이 느리고 휴대폰에서는 불편해요.

### 방법 2: 다른 컴퓨터에 통째로 옮기기

그 컴퓨터에서 직접 그리려면 이게 필요해요.
- Windows + **NVIDIA 그래픽카드 (VRAM 4GB 이상)**. 그래픽카드가 없거나 AMD·인텔이면 안 되거나 아주 느려요.
- `C:\AI-PIC\` 폴더 **전체**를 복사해요 (ComfyUI, 모델, PicApp 다 들어 있음). 모델까지 합치면 대략 **15GB 이상**이라 USB 외장하드가 편해요.
  큰 것: SDXL 모델 약 7GB, CLIP 비전 약 2.5GB, 기본 모델 약 2GB, ComfyUI 자체 약 3GB, ControlNet 두 개 약 1.5GB.
- 새 컴퓨터에서도 `C:\AI-PIC\` 에 똑같이 두면 그대로 켜져요. 새 컴퓨터에서도 **업데이트** 버튼으로 새 버전을 받아요.
- Aseprite 는 다시 빌드해야 할 수 있어요 (`aseprite\Aseprite_빌드.bat`).

## Claude 에서 쓰기 (Claude 데스크톱 앱)

Claude 데스크톱 앱에서 말로 그림 도구를 쓸 수 있어요. 예: "그림 도구로 갈색 고글 쓴 소녀 캐릭터 그려줘", "방금 그린 그림을 밤 분위기로 바꿔줘", "그걸 64 도트로 만들어줘".
Claude 가 기능(탭)과 칸을 스스로 골라 채우고, 다 그리면 그림을 대화에 보여 주고 파일 위치를 알려 줘요.

준비 (처음 한 번만):
1. 이 컴퓨터에 **Claude 데스크톱 앱**을 설치하고 로그인해요 (https://claude.ai/download).
2. `PicApp\Claude_연결_설정.bat` 을 더블클릭 → **1** 을 누르고 Enter.
3. Claude 앱을 **완전히** 껐다 켜요. 창만 닫으면 안 꺼져요. 화면 오른쪽 아래 트레이의 Claude 아이콘 → 오른쪽 클릭 → **종료**.
4. 다시 켠 뒤 대화창 아래 도구(연결) 메뉴에 **picapp** 이 보이면 연결된 거예요. 처음 쓸 때 "허용할까요?" 가 뜨면 허용해요.

쓰기:
- 그림 도구를 미리 켜 두지 않아도 돼요. 꺼져 있으면 Claude 가 켜요 (검은 창이 떠요. 처음엔 ComfyUI 가 켜지는 데 1분쯤 걸려요).
- 오래 걸리는 그림은 Claude 가 "아직 그리는 중" 이라고 하고 이어서 기다려요. 실패가 아니에요. 그림 도구를 미리 켜 두면 더 빨라요.
- 그림을 올려서 고치거나 바꾸려면 **파일 위치**를 알려 줘요. 예: `C:\Users\나\Desktop\고양이.png 를 도트로 만들어줘`.
  대화창에 그림을 끌어다 놓는 것만으로는 그림 도구에 전달되지 않아요.
- 그림 도구 화면에서 그린 그림도 "방금 그린 그림" 이라고 하면 Claude 가 결과 폴더에서 찾아요.
- 얼굴·손·소품 고치기는 붓 대신 "왼쪽 위 얼굴 부분" 처럼 말하면 Claude 가 그림을 보고 고칠 곳을 네모로 정해요. 정확히 칠하고 싶으면 그림 도구 화면에서 하세요.
- 3D 자세 만들기는 그림 도구 화면에서만 돼요.

업데이트:
- 연결 장치(`claude_mcp.py`, `claude_tools.py`)도 PicApp 폴더 안에 있어서 **업데이트 버튼으로 같이 새 버전이 돼요.** 다시 등록할 필요 없어요.
- 새 기능 탭이 생기면 Claude 도 바로 써요. 탭 목록을 그때그때 읽어 오거든요.
- 아주 가끔 `claude_mcp.py` 자체가 바뀌면 Claude 앱을 한 번 껐다 켜면 돼요 (업데이트 '바뀐 것' 목록에 보여요).
- 연결을 끊으려면 `Claude_연결_설정.bat` → **2**.
- `PicApp` 폴더를 다른 곳으로 옮기면 `Claude_연결_설정.bat` → **1** 을 다시 해요.

## 안 될 때

| 보이는 것 | 할 일 |
|---|---|
| "파이썬을 찾지 못했어요" | `PicApp` 폴더가 `C:\AI-PIC\` 안에 있는지 확인 |
| 오른쪽 위가 계속 **ComfyUI 꺼짐** | ComfyUI 검은 창에 오류가 있는지 보기. 직접 `run_nvidia_gpu.bat` 을 켜도 돼요 |
| "모델 파일이 없거나…" | `ComfyUI\models\checkpoints\dreamshaper_8.safetensors` 가 있는지 확인 |
| "…does not exist" 나 노드 이름 오류 | ComfyUI Manager에서 확장 노드(Inspyrenet-Rembg, controlnet_aux, Inpaint-CropAndStitch)가 설치돼 있는지 확인 |
| 그래픽 메모리 부족 | 다른 프로그램(게임, 브라우저 탭)을 닫고 다시 |
| "필요한 확장 노드가 ComfyUI 에 없어요" | 위 '얼굴·손 자동 다듬기 준비'를 하거나, 품질 칸의 얼굴·손을 끄기 |
| `control_v11p_sd15_lineart_fp16` 이름의 오류 | 위 '모양 지키기 준비'를 하거나 모양 지키기를 끄기 |
| `bbox/face_yolov8m.pt` 같은 이름의 오류 | 얼굴·손 모델 파일이 `ComfyUI\models\ultralytics\bbox\` 에 있는지 확인 |
